# Create DESIGN_RULES.md

Create a top-level file named `DESIGN_RULES.md` in the repository containing the exact Anti-AI Slop design rules provided by the user. This file will serve as a persistent reference for all future UI work on the project.

## Steps

1. Create `DESIGN_RULES.md` at the project root.
2. Paste the full design rules content as-is, preserving all sections and formatting.
3. No code changes or dependency installs are required.

## Outcome

The design constraints are stored in the repo and can be referenced or applied as a skill for every later change.
